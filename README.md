# Posterizarr Community Gallery

Official community preset and overlay repository for **[Posterizarr](https://github.com/fscorrupt/posterizarr)**.

Everything merged to `main` is automatically indexed into `index.json` by GitHub Actions and appears right inside the Posterizarr Web UI under:

- **Builders > Blueprint Builder > Community Gallery**
- **Builders > Dynamic Overlays > Community Gallery** (and inside the Dynamic Overlays Setup Wizard)

## Repository Layout

```text
posterizarr-community/
├── index.json                              # Auto-generated by GitHub Actions (never edit manually)
├── blueprints/
│   └── <github-username>/                  # Or <github-username>/<preset-slug>/ for multiple styles
│       ├── meta.json
│       ├── custom_blueprint.json           # Or blueprint.json (exported from Blueprint Builder)
│       └── *.jpg | *.png | *.webp          # 1–4 preview screenshots
└── dynamic-overlays/
    └── <github-username>/                  # Or <github-username>/<bundle-slug>/ for multiple bundles
        ├── meta.json
        ├── posterizarr-overlays.zip        # Or bundle.zip (exported from Dynamic Overlays)
        └── *.jpg | *.png | *.webp          # 1–4 preview screenshots
```

## How to Submit (100% in your Browser — no Git or Python needed)

1. **Export from Posterizarr:**
   - **Blueprint:** Open **Builders > Blueprint Builder**, configure your style, and click **Export** (`custom_blueprint.json`).
   - **Dynamic Overlays:** Open **Builders > Dynamic Overlays** and click **Export bundle** (`posterizarr-overlays.zip`). Posterizarr automatically strips API keys, tokens, and media server credentials.
2. **Upload in GitHub:**
   - Fork this repository, open `blueprints/` or `dynamic-overlays/`, and upload your export file + **1–4 preview screenshots** into `<your-github-username>/` (e.g. `blueprints/johndoe/`).
   - Add a tiny `meta.json` in the same folder:
     ```json
     {
       "name": "My Clean Poster Style",
       "description": "Short description of your poster or overlay setup."
     }
     ```
3. **Open a Pull Request:**
   - Submit the PR — GitHub Actions automatically validates your files and rebuilds `index.json` once merged.

See [CONTRIBUTING.md](CONTRIBUTING.md) for optional `meta.json` fields like `tags`, `notes`, or custom preview ordering.
